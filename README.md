# Sesli Asistan

Konuşarak plan, görev ve not yöneten sesli asistan uygulaması (Next.js).

## Geliştirme

```bash
npm install
npm run dev
```

Tarayıcıda [http://localhost:3000](http://localhost:3000) adresini aç.

## Ortam

`.env.example` dosyasını `.env.local` olarak kopyalayıp gerekli anahtarları doldur.
