## Nerede kaldım
- Android uygulamasında bildirimler (Seyhun: "uygulama içinde bildirim sistemini kuramaz mıyız?"; telefonda denenmedi): Web Push Android WebView'da olmadığı için uygulama Firebase Cloud Messaging kullanıyor (`@capacitor/push-notifications` 8.1.3, açıkken gelen bildirim `@capacitor/local-notifications` 8.3.1 ile gösterilir). Uygulama kayıt anahtarını alır, `users/{uid}.push.<cihaz>` = { fcm, app: "android", at, ua } yazar (`src/lib/nativePush.js`; `push.js` uygulamada izin/kayıt/kapatma/Dene için bu yolu kullanır, tarayıcıda eskisi gibi). Sunucuda bütün gönderimler `sendDevice` üzerinden (`src/lib/server/sendDevice.js`): kayıtta `fcm` varsa FCM (firebase-admin messaging, hizmet hesabıyla), yoksa Web Push; biten anahtar 410 sayılır ve silinir. İleti `fcmMessage` (src/lib/fcmMessage.js): başlık + ayrıntı, `url` (dokununca o sayfa açılır, `wireNativePush`, Pwa.jsx), etiket (aynı kayıt tek bildirim), simgede sayı, kanal "genel" (sesli, üstten görünen; MainActivity). `/api/push-test` ve `/api/push-claim` FCM anahtarını da kabul eder; `plan-reminders.mjs` ve `/api/mail/push` da `sendDevice` kullanır. Bildirim çubuğu simgesi `ic_stat_asistan` (logodaki çizgi). Android simgesi ve açılış ekranı yeni logoya (ses dalgası → onay) güncellendi. `google-services.json` depoya konmaz: GitHub gizlisi `GOOGLE_SERVICES_JSON` derlemede yazılır (`.github/workflows/android.yml`); yoksa APK bildirimsiz derlenir, uygulama çökmez (`pushReady`, DosyaPlugin). Android'de atama bildiriminin "iletildi" onayı yazılmaz. Kural değişikliği yok, yeni Netlify ortam değişkeni yok. Testleri `test:elle` › "Android bildirimi".

## Sıradaki işler
0. Firebase konsolunda Android uygulaması ekle (paket `com.seyhunyildiz.sesliasistan`), google-services.json'u GitHub › Settings › Secrets › Actions › `GOOGLE_SERVICES_JSON` olarak ekle; sonra GitHub › Actions › "Android APK" › Run workflow (ya da yeni bir birleşme) ile APK yeniden derlenir. Eski APK'yı silip yenisini kur, Ayarlar › Bildirimler'i aç, "Dene"ye bas. Başka hesaptan görev ata; uygulama kapalıyken bildirim gelmeli, dokununca görev açılmalı.
