## Nerede kaldım

- /canli rüzgâr kartı: beklenen kısmın açılışı artık kapanış kadar yumuşak (grid 0fr → 1fr; önceden max-width 0 → 54em olduğu için açılış ani görünüyordu). Kart takılınca 0,7 sn sonra açılır (elle "Rüzgâr"da durunca da açılış görünür). Seyhun 2026-11-03 18:25.
- Program kısa: bitenler tek satırda ("N start bitti"), önümüzdeki en çok 4 start, kalanı "+N start daha · son HH:MM"; başlıkta "Bugün · N start" (`PROG_MAX`). Gün bitince program yerine "Bugünün yarışları" (kazananlar) kartı gelir (önceden de böyleydi).
