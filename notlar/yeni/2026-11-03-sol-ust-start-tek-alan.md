## Nerede kaldım

- /canli yarış öncesi (Seyhun 2026-11-03 17:54, "yap" 18:02): start kartı sol üstte (`.gr-tl`). Sağ üstteki parkur/program kartı kalktı; sol altta tek alan (`.gr-pn`) sırayla rüzgâr → parkur → program. Rüzgâr adımında beklenen saatler kartın içinde 1,2 sn sonra açılır, adım bitmeden 1,8 sn önce kapanır; parkur soldan sağa açılarak çizilir. Sağ alt yarış adı + Velora aynı.
- Yarışta sol üstte sonuç olduğu için süre eskisi gibi rüzgârın üstünde (sol üstte sonuç yoksa start sol üstte).
